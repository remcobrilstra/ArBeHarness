# General-purpose personal agents (pattern layer, 2026-09-29)

Products covered from pages opened on 2026-09-29. Not OpenClaw, Grok, or Microsoft. Not Gemini CLI and not Claude Code, except where a Claude.ai help page mentions computer use is also exposed there.

- **OpenAI, consumer/work ChatGPT:** the [ChatGPT agent](https://help.openai.com/en/articles/11752874-chatgpt-agent) help article (updated 15 days before this research), [ChatGPT Atlas agent mode](https://help.openai.com/en/articles/12628199-using-ask-chatgpt-sidebar-and-chatgpt-agent-on-atlas) (updated last month), [ChatGPT Work and Codex](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex) (updated about an hour before fetch), and [cloud browser in ChatGPT](https://help.openai.com/en/articles/20001280-using-cloud-browser-in-chatgpt) (updated last month).

- **Anthropic Claude.ai:** [Claude Cowork and chat are one Claude](https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude), [computer use in Cowork](https://support.claude.com/en/articles/14128542-let-claude-use-your-computer-in-cowork), and [scheduled tasks](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork). A source conflict is load-bearing: the ChatGPT agent article’s overview says agent mode “is no longer available” and points readers to ChatGPT Work and the cloud browser, while the rest of that same article still describes agent mode as currently available on paid plans. The Work article, updated more recently, is the product OpenAI’s own overview names as the replacement. Atlas still documents a separate in-browser agent mode. Both are reported; they are not collapsed into one current product.

## What is table stakes for a general agent in 2026 versus still one product's experiment?

### Takeaway
Across ChatGPT Work, Gemini (scheduled actions plus Spark), Claude.ai, and Perplexity Computer, the repeated runtime is an account-scoped worker that chats, calls connectors and a browser, keeps personal context, runs while the laptop is closed, and can be scheduled. Full desktop control, voice as a control channel, event triggers, and sharing a scheduled task with another person are still single-vendor or narrowly rolled out.

### Cited Findings

**Presence (where the user talks to it)**

- ChatGPT Work is on web and mobile for eligible paid plans, and in the desktop app when the plan and workspace include it. Chat and Work are a toggle in one ChatGPT surface; Codex is a separate view with a separate history. Cloud Work chats sync across web, mobile, and desktop. — [ChatGPT Work and Codex](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex)
- The legacy agent article still says agent mode is on ChatGPT web, iOS/Android, and macOS/Windows desktop, paid plans only. — [ChatGPT agent](https://help.openai.com/en/articles/11752874-chatgpt-agent)
- Atlas puts Ask ChatGPT in a browser side panel, with a microphone, and Agent mode is chosen from the + menu. The agent acts in the current browsing session. — [Atlas agent mode](https://help.openai.com/en/articles/12628199-using-ask-chatgpt-sidebar-and-chatgpt-agent-on-atlas)
- Gemini Spark is only in the Gemini mobile app, the Gemini app on Mac, and gemini.google.com, and only for a personal Google Account, age 18+, Google AI Pro or Ultra, and Keep Activity on. It is unavailable in the EEA, Nigeria, Switzerland, and the UK, and not for work or school accounts. Scheduled actions are a separate Gemini Apps feature that Google says it is gradually opening to all personal Google Accounts, and that also works on a qualifying work or school Workspace account. — [Gemini Spark](https://support.google.com/gemini/answer/17094507?hl=en); [Schedule actions](https://support.google.com/gemini/answer/16316416?hl=en)
- Claude’s merged experience is rolling out gradually, starting with Pro and Max on web, desktop, and mobile. Until an account moves, Chat and Cowork stay separate modes. A task started at a desk is visible in Claude Mobile. Cowork itself is on paid plans on desktop, and in beta on web and mobile for Pro, Max, and Team, and for Enterprise when an owner enables it. — [One Claude](https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude); [Scheduled tasks](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork)
- Perplexity Computer is inside the Perplexity workspace for an active subscription, on web desktop, iOS, and Android, with no local install required for the cloud product. The user switches between Computer and Ask Anything. — [What is Computer?](https://www.perplexity.ai/help-center/en/articles/13837784-what-is-computer)

**Tools that touch the user’s life (mail, calendar, browser, files, purchases)**

- ChatGPT Work can use connected apps or plugins, a cloud browser, or both. The cloud browser reads pages, clicks, fills forms, and continues on signed-in sites after the user authenticates in a secure form. Documented task examples include restaurant availability, flights, product stock, package tracking from connected email, a DMV booking prepared for approval, utility-plan comparison, apartment listings, and reconciling invoices in accounting software. It asks for confirmation before a booking or payment. Desktop Work can use local files and desktop apps with permission; web and mobile Work cannot read files on the computer. — [Cloud browser](https://help.openai.com/en/articles/20001280-using-cloud-browser-in-chatgpt); [ChatGPT Work and Codex](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex)
- The legacy agent article says the agent uses apps as data sources and shows a composer with Web search, Box, Gmail, and Google Calendar enabled. It says signing the agent into sites lets it access email, files, or account settings and act (its examples are sharing files and changing account settings). Operator’s standalone site is no longer accessible; the article says that functionality was folded into agent mode. — [ChatGPT agent](https://help.openai.com/en/articles/11752874-chatgpt-agent)
- Atlas agent mode uses sites the user is already signed into, in “logged-in” mode, and can keep going on a tab the user already opened. It cannot run code in the browser, download files, install extensions, or access other apps or the file system. Logged-out mode uses no pre-existing cookies and does not enter accounts without specific approval. — [Atlas agent mode](https://help.openai.com/en/articles/12628199-using-ask-chatgpt-sidebar-and-chatgpt-agent-on-atlas)
- Gemini Spark’s Workspace actions, once Workspace is connected, include Calendar (read, RSVP, create, reschedule, cancel, suggest slots), Gmail (search, summarize, draft, forward, reply, labels), Drive/Docs/Sheets/Slides (search, read, rename, delete, create and edit; shared-file edits need confirmation), Keep notes, and Google Tasks. It also uses Contacts, Gemini Notebook, Google Photos, Google Search services (Search, Finance, Flights, Hotels, Maps), YouTube, several third-party apps, custom connected apps, uploaded files, and Drive files. Chrome auto-browse examples include shopping, booking travel, and dinner reservations. Spark can add items to a cart. Local Chrome sees the same signed-in sites as the user and, with permission, Password Manager logins. A remote browser is a separate cloud browser that does not inherit the local profile; sign-in stops the task until the user takes over. A remote computer also runs code, and that data persists until the user deletes it. — [Gemini Spark](https://support.google.com/gemini/answer/17094507?hl=en)
- Claude uses connected apps (examples: Google Drive, Gmail, Microsoft 365, Slack), a folder granted in Claude Desktop, a browser built into Claude Desktop or the user’s Chrome via Claude in Chrome, and, in beta, computer use that clicks and types in desktop apps. Tool order is connector, then browser, then screen. It returns documents, spreadsheets with formulas, and PowerPoint-openable decks; paid plans also get Claude Design, Claude Slides, and Claude Docs (all called beta). Computer use is Pro and Max only, macOS and Windows desktop, and is off for Team and Enterprise. The desktop must be awake and Claude Desktop open for local files, the built-in browser, and computer use. On macOS 15+, computer use works in background windows and does not take the pointer or keyboard unless the user switches to full control. — [One Claude](https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude); [Computer use](https://support.claude.com/en/articles/14128542-let-claude-use-your-computer-in-cowork)
- Perplexity Computer’s help page says it manages emails, browses, writes docs, builds slides, writes code, and chains those steps. Named authenticated integrations include Gmail, Outlook, GitHub, Linear, Slack, Notion, Snowflake, Databricks, and Salesforce, plus “hundreds of app connectors” and finance and premium data connectors. The worked example is research, a comparison table, a PPTX, and sending it through connected Gmail in one session. Default execution is a cloud sandbox; Portable Computer on supported NVIDIA hardware runs the model, orchestrator, scheduler, and sandbox locally, and escalates web or frontier-model steps to the cloud only with permission. — [What is Computer?](https://www.perplexity.ai/help-center/en/articles/13837784-what-is-computer)

**Memory and personal data**

- Sharing a ChatGPT Work scheduled task does not transfer saved memories or custom instructions. Atlas agent mode can use browser memories, if enabled, about sites previously visited. The legacy agent article says chats, browsing history, and screenshots stay until the user deletes the chat, and deleted chats and screenshots are removed from OpenAI systems within 90 days. — [ChatGPT Work and Codex](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex); [Atlas agent mode](https://help.openai.com/en/articles/12628199-using-ask-chatgpt-sidebar-and-chatgpt-agent-on-atlas); [ChatGPT agent](https://help.openai.com/en/articles/11752874-chatgpt-agent)
- Gemini Spark may use Personal Intelligence: memory of past Gemini chats, saved instructions, and the Google apps connected to Personal Intelligence, plus location. Scheduled actions that depend on location keep using the location where the action was created. Keep Activity must be on for both Spark and scheduled actions. Spark also saves remote-browser cookies, including website sign-in, across sessions until the user deletes remote browser data or Google deletes it. — [Gemini Spark](https://support.google.com/gemini/answer/17094507?hl=en); [Schedule actions](https://support.google.com/gemini/answer/16316416?hl=en)
- In the merged Claude experience, Claude uses what it remembers from chats inside tasks. Projects keep files, instructions, and context. Cloud Cowork shares chat memory. By default it does not save topics some people consider sensitive, such as health, unless “Include sensitive topics in memory” is on. Government ID numbers, criminal history, financial account numbers, and immigration status are never saved. Memory from Cowork tasks that ran only on the computer stays with those tasks. Users can view, edit, and delete memory. — [One Claude](https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude); [Computer use](https://support.claude.com/en/articles/14128542-let-claude-use-your-computer-in-cowork)
- Perplexity Computer’s help page says persistent memory retains context across sessions and platforms and automatically stores preferences, inside an isolated cloud sandbox. — [What is Computer?](https://www.perplexity.ai/help-center/en/articles/13837784-what-is-computer)

**Scheduling and proactive runs**

- ChatGPT Work can run once, repeat on a schedule or trigger, or monitor for changes. Eligible Plus, Pro, Business, Enterprise, Edu, and ChatGPT for Healthcare users can run a webhook task on new Gmail messages, new Slack channel messages, or GitHub pull-request activity in an authorized repo. Enterprise, Edu, and Healthcare admins must enable “Allow event-triggered scheduled tasks.” Healthcare event tasks are not under a BAA and must not carry PHI. Triggers are created on web or supported mobile apps, not in the desktop app. The legacy agent article still says a finished task can be set to daily, weekly, or monthly from a clock icon, managed at chatgpt.com/schedules, and that each scheduled invocation counts against the agent message cap. — [ChatGPT Work and Codex](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex); [ChatGPT agent](https://help.openai.com/en/articles/11752874-chatgpt-agent)
- Gemini has two schedulers. Scheduled actions in chat: up to 10 active, recurring, prepared in the background, notified in the web app (unread chat) and on mobile (including the lock screen, depending on settings). They can be paused, edited, or deleted in settings, and Google may turn one off for inactivity. Without a Google AI plan, content can be prepared up to several hours ahead; with a plan, within the hour before delivery. Spark schedules are separate: the user states a time or an event, schedules can be paused and resumed on the task, and a schedule will not start if 15 Spark tasks are already running. If a schedule runs while the user is offline, the user may be unable to stop an unintended action. Turning Spark off pauses schedules and deletes remote browser and code-execution data, but does not delete tasks or files Spark already wrote. — [Schedule actions](https://support.google.com/gemini/answer/16316416?hl=en); [Gemini Spark](https://support.google.com/gemini/answer/17094507?hl=en)
- Claude scheduled tasks are on all paid plans (Pro, Max, Team, Enterprise). The user describes cadence in conversation, or sets it manually (hourly, daily, weekly, weekdays, or manual) with a name, prompt, approval mode, optional model, and optional folder. Each run is its own session. Runs are remote even if the computer is asleep or Claude Desktop is closed, but a scheduled task cannot be tied to a folder on the computer; if it needs local files or apps it runs only locally. The user can pause, resume, delete, edit, and run on demand from a Scheduled sidebar. Examples include inbox, Slack, and calendar briefings. — [Scheduled tasks](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork); [One Claude](https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude)
- Perplexity Computer runs in the background, monitors email, calendar, flight status, and files with condition-based triggers, and supports scheduled jobs and proactive actions such as morning briefings and deadline reminders. The help page says it is always-on when the user is off the clock, and that the laptop does not have to be open for the cloud product. — [What is Computer?](https://www.perplexity.ai/help-center/en/articles/13837784-what-is-computer)

**Approvals**

- ChatGPT cloud browser asks before opening a new website unless the user changes Settings > Cloud browser to Auto approve (the model pauses only if a URL seems unsafe) or Always allow (documented as not recommended). Per-site allow and block override that default. Site permission is separate from confirmation of consequential actions (booking, payment, other hard-to-reverse or financial, legal, or account commitments). Sign-in uses a secure form; a review model checks the request for phishing before the form is shown; the model does not see the password, and ChatGPT does not store those credentials. The session cookie then persists until it expires or the user clears site data. Voice on web and mobile cannot approve by speech; approval is on-screen. Atlas pauses so the user is watching on sensitive sites such as financial institutions, and custom instructions can name approval checkpoints. The legacy agent article lists confirmations for high-impact actions, a watch mode on certain sites, takeover mode for passwords, and a virtual-browser takeover during which screenshots are not captured. — [Cloud browser](https://help.openai.com/en/articles/20001280-using-cloud-browser-in-chatgpt); [ChatGPT Work and Codex](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex); [Atlas agent mode](https://help.openai.com/en/articles/12628199-using-ask-chatgpt-sidebar-and-chatgpt-agent-on-atlas); [ChatGPT agent](https://help.openai.com/en/articles/11752874-chatgpt-agent)
- Gemini Spark asks before sending communications, modifying data, making purchases, and submitting web forms, and before Sign in with Google. It asks the user to take control to enter passwords or payment details. Every web-browsing task asks for confirmation after a one-time Chrome connect prompt. Shared Docs, Sheets, and Slides edits need confirmation. Google Tasks bulk actions on private tasks do not. The user can stop a response or take over the local or remote browser. — [Gemini Spark](https://support.google.com/gemini/answer/17094507?hl=en)
- Claude’s composer permission setting is Manual by default (ask before each action) or Auto (continue, with automated safety checks before an action). The setting covers the whole conversation. Computer use asks before each application; some apps are off-limits by default, and investment, trading, and cryptocurrency apps are blocked. The user can block more apps. Claude asks before permanently deleting files. The manual scheduled-task form has its own approval-mode field. — [One Claude](https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude); [Computer use](https://support.claude.com/en/articles/14128542-let-claude-use-your-computer-in-cowork); [Scheduled tasks](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork)
- Perplexity’s opened page does not describe a per-action confirmation dialog. It does say cloud escalation from Portable Computer happens only with the user’s permission, and that connectors are enabled and disconnected by the user. — [What is Computer?](https://www.perplexity.ai/help-center/en/articles/13837784-what-is-computer)

**Multi-user identity**

- ChatGPT Work Cloud and Work Local are separate workspace role permissions. Work is on by default for the default role in eligible Enterprise and Edu workspaces unless an owner or admin turns it off. Browser use and network access are separate controls. An eligible user can share a cloud scheduled task; the recipient schedules their own copy and must have their own Work access, model access, and connected apps. The share does not transfer chat history, local files, device access, connector credentials, memories, custom instructions, or workspace permissions. Tasks that run only on the sender’s computer cannot be scheduled from a shared link. Event-triggered tasks can be shared the same way. The legacy agent article says Enterprise owners have an agent-mode toggle defaulting to off, role-based access, app allow-lists, Compliance API logs of conversations but not of individual agent actions, data-residency respect, and a support-requested website blocklist. — [ChatGPT Work and Codex](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex); [ChatGPT agent](https://help.openai.com/en/articles/11752874-chatgpt-agent)
- Claude Team and Enterprise admins control Cowork with an admin toggle. Computer use is not on Team or Enterprise. Dispatch, the phone-to-desktop assign path, is closed to new users. — [Scheduled tasks](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork); [Computer use](https://support.claude.com/en/articles/14128542-let-claude-use-your-computer-in-cowork); [One Claude](https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude)
- Gemini Spark cannot be used with a work or school Google Account. Scheduled actions can, on a qualifying Workspace edition. — [Gemini Spark](https://support.google.com/gemini/answer/17094507?hl=en); [Schedule actions](https://support.google.com/gemini/answer/16316416?hl=en)
- The opened Perplexity page treats Computer as one subscriber’s workspace. It does not describe org roles, shared agents, or a second user acting with the first user’s connectors. — [What is Computer?](https://www.perplexity.ai/help-center/en/articles/13837784-what-is-computer)

**Voice**

- ChatGPT Voice adds a live voice interface to Work on web, iOS, and Android, and to Work and Codex in the desktop app. The user can speak and interrupt. If the call ends while a task is running, Work can continue it in text. Only one Voice conversation runs at a time. On web and mobile, spoken approval is not supported. Desktop Voice may also require Screen & Audio Recording and Accessibility permissions when computer context is used. Atlas’s side panel has a microphone for the prompt. — [ChatGPT Work and Codex](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex); [Atlas agent mode](https://help.openai.com/en/articles/12628199-using-ask-chatgpt-sidebar-and-chatgpt-agent-on-atlas)
- None of the Gemini, Claude, or Perplexity pages opened for this pass describe a voice session that starts or steers the agent.

**Reusable instructions, sub-agents, and metering (adjacent, but repeated)**

- Gemini skills are reusable instructions the user can invoke with `/` or that Spark can apply on its own. Skills remain available without a Google AI subscription; Spark tasks do not. Claude skills and plugins are part of the merged product, and scheduled tasks can use the same connectors, skills, and plugins as a normal task. Atlas agent mode has its own custom-instruction box for sources, required steps, and approval checkpoints. — [Gemini Spark](https://support.google.com/gemini/answer/17094507?hl=en); [One Claude](https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude); [Scheduled tasks](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork); [Atlas agent mode](https://help.openai.com/en/articles/12628199-using-ask-chatgpt-sidebar-and-chatgpt-agent-on-atlas)
- Perplexity Computer uses domain sub-agents (market research, financial analysis, news monitoring, and a coordination agent) and parallel web search. Credits: Max gets 10,000 credits a month; consumer Pro does not include a monthly credit allotment; a limited-time bonus is stated as 35,000 extra credits for paid Max and 4,000 for paid Pro, expiring in 30 days. Ask-mode search does not use credits. If credits run out, active Computer tasks pause and resume when credits return; they are not cancelled. Auto-refill is off until the user enables it. — [What is Computer?](https://www.perplexity.ai/help-center/en/articles/13837784-what-is-computer)
- Legacy ChatGPT agent message caps on that article are Plus 40, Pro 400, and Business and Enterprise 40 messages a month, with flexible-priced Business and Enterprise at 30 credits per message. Only the initial user-initiated request counts, not clarifications or authentication steps. The Work article does not repeat those caps; it says Work follows Codex usage and credits, and that longer tasks vary. — [ChatGPT agent](https://help.openai.com/en/articles/11752874-chatgpt-agent); [ChatGPT Work and Codex](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex)
- Gemini Spark allows 15 tasks running at once. Usage is compute-based and rises with the Google AI tier. — [Gemini Spark](https://support.google.com/gemini/answer/17094507?hl=en)

### Inferences
- Table stakes for a general agent, because at least three of these four document them, are: one account that is reachable from web and phone as well as desktop; a long task that keeps running after the client closes; first-party connectors for mail, calendar, and files rather than only a browser; a separate cloud browser that does not inherit the user’s local profile; a schedule the user can pause; cross-session memory or saved instructions; and a human gate on purchases, sends, or other hard-to-undo actions, with passwords entered by the user rather than typed into the chat. Claude is the partial exception on the cloud browser, because its documented browser is the desktop app’s browser or the user’s Chrome, and those need the desktop app open.
- Still one product’s experiment, or at most two and not the same design: acting inside the user’s already-logged-in browser (Atlas, and Gemini’s local Chrome auto-browse); unsandboxed control of arbitrary desktop apps (Claude computer use); live voice that can start the agent but cannot approve (ChatGPT Work); webhook triggers on Gmail, Slack, and GitHub (ChatGPT Work); sharing a scheduled task as a credential-free copy (ChatGPT Work); domain sub-agents plus credit pause/resume (Perplexity); a personal-data graph across Photos, Contacts, Search, and YouTube (Gemini Personal Intelligence); and an explicit “auto” mode that skips per-step asks (Claude).
- OpenAI is mid-migration. A harness that copied only the July 2025 “agent mode” story would miss the split the current help pages actually describe: Work as the cloud agent, Atlas as an in-browser agent with no filesystem, and Codex as a separate repo worker.

### Gaps
- Perplexity’s scheduled-task, memory, and permission articles exist in the help-center index titles, but this pass opened only “What is Computer?”. Condition triggers, sub-agents, credits, and the sandbox are from that page. A per-action approval policy, voice, and org identity for Computer were not on it.
- No opened Gemini, Claude, or Perplexity page documents voice control of the agent. Absence on these pages is not proof the products lack a voice mode elsewhere.
- The legacy ChatGPT agent article contradicts itself on whether agent mode still exists, and it disagrees with the newer Work article on how usage is metered. Which limits a user actually hits today was not verified in a product UI.
- Claude project sharing, artifact sharing, and whether a Team plan can share a Cowork session were not on the pages opened. Dispatch’s permission model was not opened; the merged-experience page only says new users cannot start it.
- Manus and Rabbit were not reviewed.

## How does the session model differ from a repo-scoped coding agent (always-on, multi-channel, proactive)?

### Takeaway
These products are account sessions, not a checkout of one repository. The same person continues a task from the phone, the web, and a desktop app; cloud work outlives the device; and a schedule or an event can start a run with nobody at the keyboard. A coding surface, when it exists, is a separate mode with its own history or a tool inside the general session.

### Cited Findings
- OpenAI separates the products in the client. Chat is conversational. Work is the multi-step agent and can produce a document, spreadsheet, presentation, report, or site. Codex is for a repository, tests, and commands, and its history stays separate from ChatGPT history. From a project the user explicitly chooses Chat or Work; Work then uses that project’s context. Cloud Work syncs across web, mobile, and desktop. Local chats still may store messages and task context in the cloud. Codex Cloud keeps coding tasks going while the computer sleeps, but remote control of a desktop Codex chat does not copy that chat into web or mobile history. — [ChatGPT Work and Codex](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex)
- A ChatGPT cloud-browser task started on web or mobile continues after the user leaves the conversation or closes the computer, and pauses for input, sign-in, or confirmation. The cloud browser does not see the device’s tabs, history, passwords, cookies, or extensions. — [Cloud browser](https://help.openai.com/en/articles/20001280-using-cloud-browser-in-chatgpt)
- Atlas is the opposite binding: the agent runs in the user’s current browsing session and is built to continue a tab the user already started. It cannot see the file system. — [Atlas agent mode](https://help.openai.com/en/articles/12628199-using-ask-chatgpt-sidebar-and-chatgpt-agent-on-atlas)
- Gemini Spark tasks are threads with a work panel (progress, files, schedules, skills and apps). The user can redirect in the thread. Local Chrome browsing stops being local if the device sleeps; Spark may switch that task to the remote browser. Sign-in on the remote browser waits for the user. Schedules fire without a new prompt. Scheduled-action results come back as a chat, marked unread on the web and as a phone notification. The user can also ask the Mac Gemini app to act from another device; the opened page only points at a separate “remote control” article for how. — [Gemini Spark](https://support.google.com/gemini/answer/17094507?hl=en); [Schedule actions](https://support.google.com/gemini/answer/16316416?hl=en)
- Claude keeps quick questions and longer tasks in one Recents list in the new experience, and several tasks can run at once. Cloud work continues if the laptop is closed, unless the task needs local files or apps, which need Claude Desktop open. The phone can watch, answer Claude’s questions, and redirect, or start a cloud task. A scheduled run is a new Cowork session, not a continuation of the chat that created it, and it cannot attach a local folder. Incognito chats still open in the old experience and cannot create files or run code. Dispatch is how existing users assign desktop work from the phone; it is not offered to new users. — [One Claude](https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude); [Scheduled tasks](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork)
- Perplexity splits Ask Anything (search) from Computer (the agent). Computer tasks run asynchronously in the cloud, can be started from web or the phone, and can fire on a schedule or on a condition such as flight status. Portable Computer is the opt-in local session. — [What is Computer?](https://www.perplexity.ai/help-center/en/articles/13837784-what-is-computer)
- Proactive scope differs. ChatGPT Work documents both clocks and app events (Gmail, Slack, GitHub). Gemini documents clocks for chat actions, and time-or-event schedules for Spark, without naming the event sources on the Spark overview beyond “after an event.” Claude documents calendars of hourly through weekly plus on-demand, not an external webhook. Perplexity documents condition monitors on email, calendar, flights, and files. — [ChatGPT Work and Codex](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex); [Gemini Spark](https://support.google.com/gemini/answer/17094507?hl=en); [Scheduled tasks](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork); [What is Computer?](https://www.perplexity.ai/help-center/en/articles/13837784-what-is-computer)

### Inferences
- Relative to a repo-scoped coding agent, the session is not “this working tree, this branch, this terminal.” It is a person, a set of connected accounts, and a mix of cloud state and optional device state. Closing the laptop ends only the slice that needs the device.
- Multi-channel here means the same vendor’s web, mobile, and desktop apps, not an open set of messengers. Slack appears as a connector or a trigger source, not as the place the agent’s session lives, on the pages opened.
- The coding-agent boundary is explicit at OpenAI (Codex history is not Work history) and softer at Claude (a Code tab remains, but the new session is one conversation that may or may not write code). Perplexity puts code execution inside Computer rather than in a repo session.
- A scheduled run is often a fresh session with stored instructions, not a resumed transcript. Claude says that directly. ChatGPT’s share flow copies instructions onto the recipient’s own schedule and withholds the sender’s history. That is a different object from a shared IDE session.

### Gaps
- Whether ChatGPT Work’s event triggers wake an existing chat or spawn a new one is not stated on the Work page.
- Gemini’s “control the Mac app from another device” article was not opened, so what is remote-controlled (screen, files, or only Spark tasks) is unknown here.
- Perplexity’s page says tasks and sessions exist, but not whether a scheduled run reuses conversation state.
- No opened page describes an always-on daemon on the user’s machine. “Always-on” in these docs means cloud runs plus, for Claude and Atlas and Gemini local browse, a desktop app that must stay open.

## What permission and safety model do they document for actions outside a workspace?

### Takeaway
Outside a project folder, all three vendors with a full safety write-up (OpenAI, Google, Anthropic) use the same shape: the user connects accounts and sites, the agent must stop for sign-in and for money or sending, passwords are not typed into the chat, and prompt injection is named as a residual risk the user still has to watch. They differ on whether the browser is the user’s or a remote one, and on whether desktop control is sandboxed.

### Cited Findings
- **OpenAI cloud browser (isolated session).** It has its own cookies and sign-ins. Default is ask-before-a-new-site, with Auto approve and Always allow as weaker settings, plus per-site allow and block. Allowing a site does not allow a consequential action. Confirmation is required before actions that are hard to reverse or that create a financial, legal, account, or other real-world commitment, including a booking or a payment. Credentials go to the remote browser through a form the model cannot see, after a review model checks for phishing. Cookies then persist across tasks until expiry or until the user clears them. The user can take over the remote browser. OpenAI says its tests for prompt injection, phishing, and unintended actions do not eliminate the risk. Workspace admins have a separate browser-use and network control. — [Cloud browser](https://help.openai.com/en/articles/20001280-using-cloud-browser-in-chatgpt); [ChatGPT Work and Codex](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex)
- **OpenAI Atlas (the user’s session).** Logged-in mode acts as the user on sites already signed in, and can use browser memories. Logged-out mode does not. The agent cannot run browser code, download files, install extensions, or touch other apps or the file system. It pauses for the user to watch on specific sensitive sites such as financial institutions. — [Atlas agent mode](https://help.openai.com/en/articles/12628199-using-ask-chatgpt-sidebar-and-chatgpt-agent-on-atlas)
- **OpenAI legacy agent article, still the only page with the long safety write-up.** High-impact actions need user confirmation. Some sites require watch mode. Takeover mode is how passwords should be entered; screenshots pause while the user has the virtual browser. Cookies persist. Users are told to enable only the apps needed, avoid vague prompts such as “check my email and handle everything,” clear remote browser data after sensitive sessions, and expect a blocklist of sites. The documented prompt-injection example is a restaurant search that tries to pull a Gmail password-reset code and send it to an attacker. Enterprise data is not used for training by default. Plus and Pro screenshots follow the consumer privacy policy and the “Improve the model for everyone” toggle. Authorized staff and providers may access agent content, including screenshots, for abuse, support, legal, or training if the user has not opted out. Business, Enterprise, and Edu conversations appear in the Compliance API; individual virtual-computer actions, app requests, and chain of thought do not. Enterprise owners can have domains blocked by contacting OpenAI. The article says these measures do not eliminate the risk. — [ChatGPT agent](https://help.openai.com/en/articles/11752874-chatgpt-agent)
- **Gemini Spark.** Local Chrome is the user’s browsing state, including signed-in sites, and may share name, contact information, files, preferences, and other sensitive info with third-party sites. Password Manager is used only with permission. The remote browser does not start signed in; the user takes over for Sign in with Google or a manual login, and cookies can be saved afterward. Confirmation is designed in before sending, modifying data, purchases, and web-form submits. Passwords and payment details are a take-control pause, and the help text says not to put them in the task thread. Shared office-file edits need confirmation. Private Google Tasks can be bulk-edited without confirmation. Spark is described as experimental. Prompt injection is defined, with examples of exfiltrating email, posting private info, or running a malicious command via the remote computer. Mitigations named: confirmation prompts, prohibited-task recognition, take-control, a visible plan, and restricting browsing to sites relevant to the task. Google says those do not guarantee safety, and that an offline schedule may finish an action the user cannot stop. Supervision is stated as the main control. Remote browser data and remote code-execution data can be deleted; turning Spark off deletes both. Undo of a Workspace action is a link in Spark’s confirmation that opens the Workspace service. — [Gemini Spark](https://support.google.com/gemini/answer/17094507?hl=en)
- **Claude computer use and Cowork.** There is no sandbox between Claude and the apps on screen. Claude screenshots the screen and therefore can see whatever is visible, including other people’s data. Permission is per app, every session, with a user blocklist and a default block on investment, trading, and cryptocurrency apps. A link clicked in an allowed app can still open a browser the user did not allow; Claude can be prevented from seeing that window but not from the open. Training tells Claude to avoid transferring funds, modifying or deleting files, entering sensitive data, stock and investment transactions, and scraping facial images. The help page says those guards are not absolute and advises against banking, healthcare, government, legal, medical, and other people’s personal data. Prompt-injection scans run, and the user can stop Claude. Manual versus Auto is a conversation-level switch; Auto still runs safety checks, and the user is told to stay close for sending messages or changing important files. File delete asks by default. Local reach (files, built-in browser, computer use) exists only while Claude Desktop is open, and only for folders the user connected. Scheduled cloud tasks cannot see a local folder. Computer use is beta, Pro and Max only. — [Computer use](https://support.claude.com/en/articles/14128542-let-claude-use-your-computer-in-cowork); [One Claude](https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude); [Scheduled tasks](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork)
- **Perplexity, from the one page opened.** The default is a secure cloud sandbox isolated from the machine. Portable Computer keeps files and agent activity on supported NVIDIA hardware, and web or frontier-model steps go to the cloud only with permission. Connectors are explicit enable, install, and disconnect actions. The page claims an email can be sent through connected Gmail as part of one prompt and does not say whether that send waits for a second confirmation. — [What is Computer?](https://www.perplexity.ai/help-center/en/articles/13837784-what-is-computer)

### Inferences
- The documented safety model is not a workspace ACL on paths inside a repo. It is four layers, and products implement different subsets: (1) which accounts and sites are connected at all, (2) a remote browser identity that starts logged out, distinct from the user’s browser, (3) a stop for irreversible or money-moving actions and for credentials, (4) admin policy for a company workspace (OpenAI and Claude) that a personal Gemini Spark user does not have.
- Acting as the user on an already logged-in browser is the dangerous mode, and both OpenAI (Atlas logged-in versus logged-out; cloud browser versus device browser) and Google (local Chrome versus remote browser) document it as opt-in and easy to mistake for the safer default.
- Unsandboxed computer use is the outlier. Claude says so in those words. The other three, on the pages opened, put general web work in a cloud browser or sandbox and reach the local machine only through a granted folder, a desktop permission, or an optional local appliance.
- Residual risk is part of the contract, not a footnote. OpenAI, Google, and Anthropic each say the safeguards do not cover prompt injection or user absence. A scheduled run while the user is offline is the case Gemini explicitly says may be unstoppable.

### Gaps
- Perplexity’s confirmation behavior before sending mail, paying, or changing a third-party record was not on the page opened. Do not treat the sandbox sentence as an approval policy.
- The Claude “Use Claude Cowork safely” article is linked from the pages above but was not opened. Extra rules that exist only there are missing from these notes.
- OpenAI’s cloud-browser article and the legacy agent article overlap and were updated on different clocks. Where they disagree (for example, whether screenshots are paused in takeover, which is only in the legacy article), the newer cloud-browser page is the one that describes Work’s current browser. It does not repeat the human-review or Compliance API sections.
- No opened page states a formal allow-list of purchase merchants, a spending cap, or a guaranteed undo for a completed booking or payment. Gemini’s undo note is for Workspace edits, via a link, not for web checkouts.
